# MVP Specification

## Dashboard
Show:
- Revenue
- Expenses
- Estimated profit
- Number of customers
- Open leads
- Recent sales
- Recent expenses

## Customers
Create, edit and view:
- Name
- Phone
- Email
- Notes

## Products / Services
Create:
- Name
- Description
- Price
- Active status

## Sales
Record:
- Customer
- Product/service
- Quantity
- Amount
- Date

## Expenses
Record:
- Category
- Description
- Amount
- Date

## Principle
Keep the first version simple enough for a small business owner to understand without training.
